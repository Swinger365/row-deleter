◆ cleanWorkbook()

CleanReport redclean::cleanWorkbook ( const CleanOptions &  options)

Очищает содержимое строк с красными ячейками на выбранных листах.

Работает в несколько параллельных этапов:

  1. распаковка и разбор XML — по задаче на лист;
  2. поиск красных строк — куски по CleanOptions::rowsPerTask строк всех листов;
  3. очистка и сериализация — по задаче на лист (pugixml не допускает параллельной записи в один документ);
  4. сжатие изменённых частей кусками и запись архива.

Если ни одна строка не найдена, файл не перезаписывается (кроме случая, когда выходной путь отличается от входного — тогда книга копируется).

Аргументы
optionsПараметры.
Возвращает
Отчёт.
Исключения
std::invalid_argumentЕсли параметры некорректны или лист не найден.
std::runtime_errorЕсли книгу не удалось прочитать или записать.

◆ deflateChunk()

std::string redclean::deflateChunk ( const char *  data,
std::size_t  size,
int  level,
bool  last 
)

Сжимает фрагмент raw-deflate потока.

Фрагменты, сжатые с last = false (сброс до границы байта без признака конца потока), и последний фрагмент с last = true можно просто склеить — получится корректный поток. Так одну большую часть можно сжимать параллельно. Потокобезопасна.

Аргументы
dataНачало фрагмента.
sizeРазмер фрагмента.
levelУровень deflate 1..9.
lastПоследний ли это фрагмент потока.
Возвращает
Сжатый фрагмент.

◆ shiftFormula()

std::string redclean::shiftFormula ( std::string_view  formula,
std::int64_t  dRow,
std::int64_t  dCol 
)

Сдвигает относительные ссылки формулы так, как Excel делает при копировании.

Поддерживаются ссылки A1, A$1, $A1, диапазоны A1:B2, целые столбцы A:C и строки 1:3, в том числе с именем листа. Абсолютные части ($) не меняются; строки в кавычках, имена листов, функций и структурированные ссылки (Table1[Col]) не трогаются. Ссылка, ушедшая за пределы листа, заменяется на #REF!.

Аргументы
formulaТекст формулы без ведущего '='.
dRowСдвиг по строкам.
dColСдвиг по столбцам.
Возвращает
Новый текст формулы.
