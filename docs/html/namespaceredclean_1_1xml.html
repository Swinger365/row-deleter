◆ kParseFlags

constexpr unsigned redclean::xml::kParseFlags = pugi::parse_default | pugi::parse_declaration | pugi::parse_ws_pcdata
constexpr

Флаги разбора, сохраняющие документ максимально близким к исходному.

Сохраняются объявление XML и текстовые узлы из одних пробелов (важно для <t xml:space="preserve">).
