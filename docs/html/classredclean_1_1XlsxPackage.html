Подробное описание

Книга .xlsx как набор частей.

Разбирает _rels/.rels, workbook.xml и его связи, чтобы найти листы, стили, тему и цепочку вычислений. Изменённые части хранятся в памяти до saveAs; все остальные при сохранении копируются байт в байт.

Потокобезопасность: read можно вызывать одновременно из разных потоков, если в это время никто не вызывает изменяющие методы; остальные методы — из одного потока.

Сохраняет книгу.

Изменённые части режутся на куски по 4 МиБ, которые сжимаются параллельно в pool; неизменённые копируются из исходного архива без пересжатия. Порядок записей исходного архива сохраняется.

Аргументы
pathПуть в UTF-8; может совпадать с исходным.
poolПул потоков для сжатия.
compressionLevelУровень deflate 1..9.
Исключения
std::runtime_errorПри ошибке записи.
