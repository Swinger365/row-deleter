Возвращает аргументы командной строки в UTF-8.

В Windows argv приходит в ANSI-кодировке, поэтому аргументы берутся через CommandLineToArgvW и перекодируются; заодно консоль переключается на UTF-8. На остальных системах аргументы используются как есть.

Аргументы
argcЧисло аргументов из main.
argvАргументы из main.
Возвращает
Все аргументы, включая имя программы.
