Подробное описание

Обработка одного листа (xl/worksheets/sheetN.xml) в три этапа.

  1. load — разбор XML; разные листы можно разбирать параллельно.
  2. detect — поиск красных строк; можно вызывать параллельно для непересекающихся диапазонов, документ при этом только читается.
  3. apply — очистка найденных строк; pugixml не допускает одновременных изменений одного документа, поэтому этап выполняется одним потоком на лист.

Очистка удаляет значения, формулы и тип ячейки, оставляя адрес и стиль, — как команда «Очистить содержимое» в Excel.
