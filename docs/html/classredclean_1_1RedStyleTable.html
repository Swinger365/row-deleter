Подробное описание

Таблица «индекс стиля ячейки (атрибут s) → красный или нет».

Строится один раз из styles.xml, после чего только читается, поэтому безопасна для одновременного доступа из нескольких потоков.

Строит таблицу по частям книги.

Учитываются цвета rgb, theme (с tint) и indexed, в том числе пользовательская палитра <indexedColors>. Для узорной заливки проверяются цвет узора и фона, для градиентной — все опорные точки.

Аргументы
stylesXmlТекст xl/styles.xml; пустой — все стили не красные.
themeXmlТекст части темы; может быть пустым.
optionsПараметры анализа.
Возвращает
Таблица стилей.
Исключения
std::runtime_errorЕсли XML некорректен.
