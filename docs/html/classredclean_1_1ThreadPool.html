Подробное описание

Пул потоков фиксированного размера с общей очередью задач.

Задачи не должны блокироваться в ожидании других задач того же пула — иначе при занятых потоках возможна взаимная блокировка. Деструктор дожидается выполнения всех поставленных задач.
